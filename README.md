# Design and Analysis of Algorithms（MIT 6.046J）

MIT 6.046J *Design and Analysis of Algorithms* 课程资料整理（讲义、习题课、习题集、复习与考试、代码打印稿）。

## 目录结构

```
01-讲义/          按讲次组织（lec01 ~ lec20），讲义与图示资源随讲次存放
02-习题课/        Recitation Notes 01–11
03-习题集/        Problem Set 01–10（题目 + 解答）
04-考试/          Quiz 1 / Quiz 2 / Final + 解答
05-复习资料/      Review / 复习讲义
06-代码/          代码练习题解（17 篇，纯文本等宽排版 PDF，带行号）
00-课程计划.pdf   课程大纲与进度
```

## 各目录用途

| 目录 | 内容与用途 |
| --- | --- |
| `01-讲义/` | Lecture Notes Lec 01–24（Lec 14 拆 14A Network Flow / 14B Baseball Elimination）。**批注工作区**——看视频/读 CLRS 时直接在纸面记笔记，每讲 8–24 页（含图） |
| `02-习题课/` | Recitation 01–11 讲义（例题 + 推导一体）。**实例化练习**——把抽象算法落成具体计算 |
| `03-习题集/` | Problem Set 01–10 题目 + Solutions。**做题 + 纸面改错**（配合「先攻后守」：先闭卷做题，再对照解答） |
| `04-考试/` | Quiz 1 / Quiz 2 / Final Exam + 对应 Solutions。**阶段自测** |
| `05-复习资料/` | Review / 复习讲义 |
| `06-代码/` | 代码实现对应的 PDF 打印稿（行号 + 标题分隔头，等宽排版）。**打印精读**——自己实现后对照纸面逐行标注差异 |

## 整理说明

- `01-讲义/` 以**讲次（lecNN）**为粒度组织，不再按文件类型细分。
- 早期重复文件（`05-代码打印.zip` 与 `06-代码/` 内容完全相同）已去重。

## 打印建议

1. 双面打印；讲义图多，可 2-up 缩印省纸，代码同理。
2. 讲义是「批注工作区」，**不要**覆膜。
3. Recitation 与讲义同步打印；复习资料考前一周再打。
