<span style="color:#2471a3;">**[section]**</span> <span style="color:#00838f;">**多项式操作与表示（Polynomial operations and representation）**</span>

多项式（polynomial）$A(x)$ 可以写成以下形式：

```math
A(x) = a_0 + a_1 x + a_2 x^2 + \cdots + a_{n-1} x^{n-1} = \sum_{k=0}^{n-1} a_k x^k = (a_0, a_1, a_2, \ldots, a_{n-1})
```

其中最后的 $(a_0, a_1, \ldots, a_{n-1})$ 是**系数向量**（coefficient vector）。$A$ 的次数（degree）为 $n-1$。

<span style="color:#2471a3;">**[section]**</span> <span style="color:#00838f;">**多项式上的操作（Operations on polynomials）**</span>

多项式有三种主要操作。

1. **求值（Evaluation）**：给定多项式 $A(x)$ 和一个数 $x_0$，计算 $A(x_0)$。这可以用 $O(n)$ 次算术操作在 $O(n)$ 时间内完成，方法是 **Horner 法则（Horner's rule）**。
   - **Horner 法则**：$A(x) = a_0 + x\big(a_1 + x\big(a_2 + \cdots x(a_{n-1}) \cdots \big)\big)$。每一步先做一次求和，再乘以 $x$，然后进入下一步。因此需要 $O(n)$ 次乘法与 $O(n)$ 次加法。
2. **加法（Addition）**：给定两个多项式 $A(x)$ 与 $B(x)$，计算 $C(x) = A(x) + B(x)$（对所有 $x$）。这用基本算术即可在 $O(n)$ 时间内完成，因为 $c_k = a_k + b_k$。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答的设计问题是：在一个固定点上给 polynomial（多项式）求值，到底哪一步在做重复劳动，能不能把这份重复整体消掉。教科书式的 evaluation（求值）是先算出 $x^2, x^3, \ldots, x^{n-1}$ 存成一个数组，再逐项乘系数求和；Horner's rule（霍纳法则，也叫嵌套乘法）把它改写成层层嵌套的形状：
>
> ```math
> A(x) = a_0 + x\left(a_1 + x\left(a_2 + \cdots + x\,a_{n-1}\right)\cdots\right)
> ```
>
> 因果链可以逐句拆开。最内层只有一个系数 $a_{n-1}$，它不需要任何幂次；每向外剥掉一层括号，动作都是「先把累加器乘一次 $x$、再加一个系数」。整个过程中 $x$ 只作为同一个固定乘数反复出现，中间量里从来没有出现过 $x$ 的任何次幂 —— 这正是它与「先造幂表再点乘」的根本分野：后者把一个长度为 $n$ 的辅助数组显式造出来，前者把这个数组携带的全部信息压进一个累加变量。
>
> 有人会立刻反问：如果我把幂表增量地建起来（用 $x^k = x^{k-1}\cdot x$），乘法次数不也是 $O(n)$ 吗？是，但那是 $2n-2$ 次：$n-1$ 次造幂，$n-1$ 次乘系数。嵌套写法把这两件事合并成同一件事，乘法数直接减半，辅助空间从 $O(n)$ 降到常数个变量。若换三种写法看同一句「求值 $O(n)$」：按定义内层再套一层循环重算幂，是 $O(n^2)$；用快速幂逐项求 $x^k$，是 $O(n\lg n)$；只有把幂复用到底，才是 $O(n)$。差别全在「重复的幂有没有被复用」这一件事上。
>
> 手算一遍。取 $A(x) = 3x^4 - 2x^3 + 0\cdot x^2 + 5x - 7$，系数从低到高排成 $(-7, 5, 0, -2, 3)$，在 $x = 2$ 处求值。从最高次开始走：先取 $3$；乘 $2$ 加 $-2$ 得 $4$；乘 $2$ 加 $0$ 得 $8$；乘 $2$ 加 $5$ 得 $21$；乘 $2$ 加 $-7$ 得 $35$。一共 $4$ 次乘法加 $4$ 次加法，答案是 $35$。核对：$3\cdot 16 - 2\cdot 8 + 0 + 10 - 7 = 48 - 16 + 10 - 7 = 35$，对上。若先造幂表 $2, 4, 8, 16$（$4$ 次乘法）再逐项乘系数（又是 $4$ 次乘法），总共 $8$ 次乘法，恰好两倍。
>
> 更值得注意的是那串中间值本身：$3, 4, 8, 21$。它们恰好是 $A(x)$ 除以 $(x-2)$ 所得商的系数，最后一步的 $35$ 就是那个余数。也就是说，循环每一步的累加器状态都在同时报告「商的一项」和「余数」，这跟 synthetic division（综合除法）的竖式排布是同一条计算路径的两种写法。这条对应关系把 remainder theorem（余数定理）从一句陈述变成一行可以直接执行的代码：除以 $(x - x_0)$ 所得的余数就是 $A(x_0)$。这一步不只是好看，它解释了为什么 Horner's rule 不需要预先知道 $x_0$ 是多少就能组织计算 —— 循环结构只依赖系数个数。
>
> 还有一层值得点明：Horner's rule 与原式在实数域上是同一个数，在浮点数上却不是。CSAPP 第二章讲过的浮点表示不满足结合律，乘的次序变了，舍入误差就跟着变。嵌套写法把乘加交替成一条长度 $n-1$ 的依赖链，误差累积的路径更短，通常比「先造幂表再求和」更稳；但它对系数符号敏感，某些构造下反而更差，所以这不能当成一条无条件的稳定性定理，只能算「运算次序改变结果」的又一个例子。
>
> 跨课程连接有两条。第一条是 CSAPP 第五章：那里讲的 strength reduction（强度削减）和循环不变式外提，做的事和这里完全一致 —— 把「每次迭代都要重算的东西」换成「一次算好、循环里只乘一次」；区别在于 CSAPP 盯的是指令级的常数因子（乘法换移位、内存访问提到寄存器），这里盯的是算术操作计数从 $O(n^2)$ 掉到 $O(n)$，层级不同而手法同源。第二条是 CLRS 第 30 章 30.1 节：那一节先把求值 $O(n)$ 与加法 $O(n)$ 当作既成事实摆出来，随后才引出「用点值表示绕开 $O(n^2)$ 乘法」这条主线 —— 换句话说，Horner's rule 是整章 FFT 的第一块砖，正因为系数表示下的乘法降不下来，才有必要换一种表示。
>
> 收束一句：Horner's rule 省的不是渐近阶，而是「同一个幂被反复物化」这件事本身；把重复折叠进循环，是后面 FFT 与 FFTW 都在重复使用的同一个母题。

<span style="color:#c0392b;">**多项式操作（续）**</span>

3. **乘法（Multiplication）**：给定两个多项式 $A(x)$ 与 $B(x)$，计算 $C(x) = A(x) \cdot B(x)$（对所有 $x$）。则

```math
c_k = \sum_{j=0}^{k} a_j b_{k-j} \quad \text{对} \quad 0 \le k \le 2(n-1)
```

因为结果多项式的次数是 $A$ 或 $B$ 次数的两倍。这个乘法等价于向量 $A$ 与 $\mathrm{reverse}(B)$ 的**卷积（convolution）**。卷积是「所有相对位移的内积」——这个操作在数字信号处理（digital signal processing, DSP）里同样用于平滑（smoothing）等场景。

- 朴素多项式乘法（naive polynomial multiplication）需要 $O(n^2)$。
- 通过 Strassen 式（Strassen-like）的分治技巧可以达到 $O(n^{\lg 3})$，甚至 $O(n^{1+\varepsilon})$（对任意 $\varepsilon > 0$）。
- 今天，我们将通过**快速傅里叶变换（Fast Fourier Transform）**在 $O(n \lg n)$ 时间内计算乘积！

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要钉死一件事：polynomial multiplication（多项式乘法）与 convolution（卷积）不是「类似」，而是同一个式子的两种读法。写开就是 $c_k = \sum_{j=0}^{k} a_j b_{k-j}$：要算第 $k$ 个系数，就把下标 $j$ 从 $0$ 推到 $k$，与此同时 $k-j$ 从 $k$ 退到 $0$ —— 一个涨一个落，两者之和恒为 $k$。所谓卷积，就是「固定总位移，把所有能凑出这个位移的配对逐一相乘再相加」。
>
> 这条等式换个写法就清楚了：$A(x)B(x) = \sum_k \left(\sum_{j} a_j b_{k-j}\right) x^k$。把两个多项式各自按 $x$ 的幂展开、相乘、再按幂次归并同类项，归并的依据正是 $j + (k-j) = k$。所以卷积里那个「此消彼长」不是外部定义，它就是多项式乘法在系数表上的自然投影；反过来，正因为它是自然投影，任何「先展开再归并」的算法都在隐式地做卷积。
>
> 真正让复杂度掉下台阶的是 evaluation（求值）这一步的性质：对任意一点 $x_0$ 都有 $A(x_0)\cdot B(x_0) = C(x_0)$。一句话 —— 求值保持乘法。于是在 $n$ 个点上把 $A$、$B$ 各算一遍，做 $n$ 次普通标量乘法，再把这 $n$ 个值还原成系数，乘法开销就从 $O(n^2)$ 次滑落到 $O(n)$ 次；剩下的成本全部压在「系数与点值互转」上，而那正是 FFT 要付的 $O(n\lg n)$。这里有一个容易被忽略的前提：逐点乘之所以成立，是因为多项式乘法对每个变量都是线性的，两个乘数各自的贡献不会互相干扰；若换成「一个多项式的系数去乘另一个多项式的系数的平方」这类非线性操作，同一套搬运就完全失效。
>
> 给个数。设 $A(x) = 1 + 2x + 3x^2$，$B(x) = 4 + 5x$，系数向量分别是 $(1,2,3)$ 与 $(4,5)$。按卷积公式逐项算：$c_0 = 1\cdot 4 = 4$；$c_1 = 1\cdot 5 + 2\cdot 4 = 13$；$c_2 = 2\cdot 5 + 3\cdot 4 = 22$；$c_3 = 3\cdot 5 = 15$。所以 $C(x) = 4 + 13x + 22x^2 + 15x^3$，一共 $4$ 个系数，次数为 $3$。
>
> 现在换点值路线验证，取 $n = 4$ 个点 $x \in \{1, i, -1, -i\}$，也就是四个 $4$ 次单位根。$A$ 在这四点的值是 $6$、$-2+2i$、$2$、$-2-2i$；$B$ 的值是 $9$、$4+5i$、$-1$、$4-5i$。逐点相乘得 $54$、$-18-2i$、$-2$、$-18+2i$。再直接算 $C$ 在这四点的值：$C(1) = 4+13+22+15 = 54$；$C(i) = 4 + 13i - 22 - 15i = -18-2i$；$C(-1) = 4-13+22-15 = -2$；$C(-i) = 4 - 13i - 22 + 15i = -18+2i$。四个数全部对上。这是「时域卷积等于频域逐点乘」的一次完整手算复核，不是比喻，也不是近似。
>
> 跨课程连接可以点三处，并各说清区别。一是 6.042J 的生成函数：那里把数列 $a_k$ 编码成 $\sum a_k x^k$，两个生成函数相乘对应数列的卷积，用来数「把两个独立选择拼成一个总量」的方案数 —— 路径完全一样，区别是那里 $x$ 只是形式符号、从不求值，我们这里必须真在复数点上求值才能算出系数。二是概率论里两个独立随机变量之和的分布 $P_{X+Y}(z) = \sum_x P_X(x)P_Y(z-x)$，逐字就是同一个配对；区别在于概率质量函数的支撑可以无限，总和恒为 $1$，所以那边的频域版本是特征函数而不是有限点上的变换。三是数字信号处理里的平滑滤波：一个长度为 $m$ 的滤波器扫过信号，每输出一个点就做一次「位移配对求和」，$n$ 个输出点共 $n\cdot m$ 次乘加，这就是卷积在工程里的原型。
>
> 最后收一句：把卷积搬到频域变成逐点乘，这套动作在教材里有个名字叫 convolution theorem（卷积定理）；它不是某条技巧的别名，而是「求值保持乘法」的直接推论 —— 而求值之所以能保持乘法，全靠多项式乘法对每个变量都是线性的，所以这条定理的适用范围也正好被这个线性性框住。

<span style="color:#2471a3;">**[section]**</span> <span style="color:#00838f;">**多项式的表示（Representations of polynomials）**</span>

首先考虑多项式的不同表示（representation），以及每种表示下完成各操作所需的时间。

主要有 3 种表示需要考虑。

1. **带单项式基（monomial basis）的系数向量**（coefficient vector）
2. **根 + 缩放项（Roots and a scale term）**
   - $A(x) = (x - r_0) \cdot (x - r_1) \cdots (x - r_{n-1}) \cdot c$
   - 然而，只用基本算术运算与 $k$ 次根运算，不可能找到精确的根（exact roots）。此外，在这种表示下加法极其困难，甚至不可能。乘法只需把根拼接（concatenate）起来，求值则可在 $O(n)$ 内完成。
3. **采样（Samples）**：$(x_0, y_0), (x_1, y_1), \ldots, (x_{n-1}, y_{n-1})$，满足 $A(x_i) = y_i$（对所有 $i$），且每个 $x_i$ 互不相同。根据 **Lagrange 插值**与**代数基本定理（Fundamental Theorem of Algebra）**，这些采样点唯一确定一个 $n-1$ 次多项式 $A$。加法与乘法可以通过对 $y_i$ 逐项相加/相乘完成（假设 $x_i$ 匹配）；但求值需要插值（interpolation）。

下表给出各表示与各操作的运行时间（算法 vs 表示）：

> <span style="color:#7f8c8d;">[表格说明] 下表为讲义原文中的「Algorithms vs. Representations」矩阵（行 = 操作，列 = 表示）。</span>

| 操作 \ 表示 | 系数（Coefficients） | 根（Roots） | 采样（Samples） |
|:---:|:---:|:---:|:---:|
| 求值（Evaluation） | $O(n)$ | $O(n)$ | $O(n^2)$ |
| 加法（Addition） | $O(n)$ | $\infty$ | $O(n)$ |
| 乘法（Multiplication） | $O(n^2)$ | $O(n)$ | $O(n)$ |

我们通过在 $O(n \lg n)$ 时间内**在系数与采样之间互相转换**，来综合每种表示的优势。

**怎么做？** 考虑矩阵形式的多项式。

令 $V$ 为 **Vandermonde 矩阵**（Vandermonde matrix），其元素 $v_{jk} = x_j^k$。则

```math
V \cdot A = Y
```

即系数向量 $A$ 乘 Vandermonde 矩阵 $V$ 得到采样值向量 $Y$。于是我们可用矩阵向量积 $V \cdot A$ 在系数与采样之间转换，这等价于求值，耗时 $O(n^2)$。

类似地，可以从采样转回系数：求解 $V \backslash Y$（MATLAB 记法）。这需要 $O(n^3)$（高斯消元 Gaussian elimination），或若 $V^{-1}$ 预先算好，则用 $O(n^2)$ 计算 $A = V^{-1} \cdot Y$。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要拆的是那张三行三列的表：同一个多项式被写成 coefficient vector（系数向量）、被写成根加缩放项、被写成一组 samples（采样点），三种写法在 evaluation（求值）、addition（加法）、multiplication（乘法）上的代价完全错位。表不是结论陈列，它是一张「按需换坐标」的施工图。
>
> 先看系数与采样为什么靠矩阵乘法互转。把 $v_{jk} = x_j^k$ 排成一个 $n\times n$ 的 Vandermonde matrix（范德蒙矩阵）$V$，那么 $Y = V A$ 就是把系数向量搬到采样向量的一次线性映射，$A = V^{-1}Y$ 是反向搬运。这件事能成立的前提是 $V$ 可逆，而 $V$ 可逆当且仅当那 $n$ 个 $x_j$ 两两不同：$n=2$ 时 $\det V = x_1 - x_0$；$n=3$ 时 $\det V = (x_1-x_0)(x_2-x_0)(x_2-x_1)$，只要有两列相同，行列式立刻归零。用 $n=3$、$x=(0,1,2)$ 核对一次：公式给出 $(1-0)(2-0)(2-1) = 2$；矩阵的三行分别是 $(1,0,0)$、$(1,1,1)$、$(1,2,4)$，按第一行展开得 $1\cdot(1\cdot 4 - 1\cdot 2) = 2$，两边一致。这就是「$n$ 个互异点唯一确定一个次数不超过 $n-1$ 的多项式」的矩阵语言版本。
>
> 手算一个小例子把这条路走通。取 $x = (0,1,2)$，采样值 $Y = (1,2,3)$，要求 $A(x) = a_0 + a_1x + a_2x^2$。$x_0 = 0$ 那一行只留下 $a_0$，所以 $a_0 = 1$；$x_1 = 1$ 给出 $1 + a_1 + a_2 = 2$，即 $a_1 + a_2 = 1$；$x_2 = 2$ 给出 $1 + 2a_1 + 4a_2 = 3$，即 $a_1 + 2a_2 = 1$。两式相减得 $a_2 = 0$、$a_1 = 1$，所以 $A(x) = 1 + x$。代回验证：$A(0)=1$、$A(1)=2$、$A(2)=3$，全部吻合。注意点数正好是 $3$、系数个数也正好是 $3$：少一个点就有无穷多个解，多一个点则只剩下唯一那个解仍满足全部条件，这就是表里「采样求值 $O(n^2)$」那一格背后的代价结构。
>
> 再看「根加缩放项」那一列的 $O(n)$ 乘法是怎么来的：$(x-r_0)\cdots(x-r_{n-1})c$ 乘上 $(x-s_0)\cdots(x-s_{m-1})d$，结果就是把这串根接起来、把两个缩放因子相乘，一次展开都不用做。但加法在这一列里不是「慢」，而是根本做不到：$A = x - 1$ 与 $B = -(x-1)$ 的根都是 $\{1\}$，两者相加却得到恒零多项式，连次数都不再是 $1$；反过来 $A = x$ 与 $B = x$ 相加得 $2x$，根还是 $\{0\}$。也就是说，根的信息不足以决定和的根，甚至和可能根本没有根。采样那一列没有这个问题：$(x_i, y_i)$ 与 $(x_i, z_i)$ 逐点相加得 $(x_i, y_i+z_i)$，恒零也照样表示得出来 —— 代价被转移到「从点值反求系数」那一步的 interpolation（插值）上。
>
> 跨课程连接落在 Strang 线性代数上：换一组坐标去看同一个对象，$V$ 就是「从单项式基 $1, x, \ldots, x^{n-1}$ 搬到 Lagrange 基」的过渡矩阵，而 Lagrange interpolation（拉格朗日插值）给出的正是那组基：第 $i$ 个基函数在 $x_i$ 处取 $1$、在其它点上取 $0$，长得就像单位向量。区别要说清：Strang 里的相似变换作用在同一个向量空间上、换的只是观察角度；这里的 $V$ 连接的是两个语义不同的空间（系数空间与采样空间），维度相同但不是同一个空间，所以它更像「编码器加解码器」而不是「换一副眼镜」。代数基本定理在这里的作用也很具体：两个次数不超过 $n-1$ 的多项式若在 $n$ 个点上取值相同，它们的差有 $n$ 个根，而次数不超过 $n-1$，只能恒零 —— 这条推理把「采样唯一确定多项式」从直觉变成了证明。
>
> 收束：没有任何一种表示在三列里都便宜，所以算法的骨架注定是「搬过去、做完、搬回来」，而全部技术难度都集中在怎么把搬运做成 $O(n\lg n)$ —— 这正是下一节选单位根的动机。

在系数与采样之间转换（及反向）要想超越 $\Theta(n^2)$，我们需要为 $x_0, x_1, \ldots, x_{n-1}$ 选择**特殊值**——目前我们只假设了这些 $x_i$ 互不相同。

<span style="color:#c0392b;">**分治算法（Divide and Conquer Algorithm）**</span>

我们可以把多项式乘法表述为分治算法，对多项式 $A(x)$（对所有 $x \in X$）执行以下步骤：

1. **分解（Divide）**：把 $A$ 拆成偶系数与奇系数两部分：

```math
A_{\mathrm{even}}(x) = \sum_{k=0}^{\lfloor n/2 \rfloor - 1} a_{2k} x^k = (a_0, a_2, a_4, \ldots)
```

```math
A_{\mathrm{odd}}(x) = \sum_{k=0}^{\lfloor n/2 \rfloor - 1} a_{2k+1} x^k = (a_1, a_3, a_5, \ldots)
```

---

<!-- ===== PDF p4 ===== -->

<span style="color:#c0392b;">**分治算法（续）**</span>

2. **递归征服（Conquer）**：对 $y \in X^2$ 递归地求 $A_{\mathrm{even}}(y)$ 与 $A_{\mathrm{odd}}(y)$，其中 $X^2 = \{x^2 \mid x \in X\}$。
3. **合并（Combine）**：$A(x) = A_{\mathrm{even}}(x^2) + x \cdot A_{\mathrm{odd}}(x^2)$，对所有 $x \in X$。

然而，该算法的递推式为

```math
T(n, |X|) = 2 \cdot T\!\left(\frac{n}{2}, |X|\right) + O(n + |X|) = O(n^2)
```

并不比以前更好。

**如果 $X$ 是「塌缩」的（collapsing）**，我们就可以做得更好：要么 $|X| = 1$（基础情形 base case），要么 $|X^2| = \frac{|X|}{2}$ 且 $X^2$ 是（递归地）塌缩的。此时递推式为

```math
T(n) = 2 \cdot T\!\left(\frac{n}{2}\right) + O(n) = O(n \lg n)
```

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答的问题是：divide and conquer（分治）明明已经写对了，为什么复杂度还是 $O(n^2)$，以及「塌缩」这个词究竟在技术上买到了什么。答案不在递归的结构上，而在递归子问题的输入规模上。
>
> 先把递推式的钱花在哪里算清楚。在某一层，我们手上有 $2^i$ 个子问题，每个子问题有 $n/2^i$ 个系数、要在一份点集上求值。这一层的总开销等于 $2^i$ 乘上「单个子问题的代价」。若点集不塌缩，每个子问题仍带着 $|X|$ 个点，于是单层代价 $= 2^i\left(n/2^i + |X|\right) = n + 2^i|X|$，随层数指数膨胀；把 $i$ 从 $0$ 加到 $\lg n$ 求和，得到 $n\lg n + |X|\left(2^{\lg n + 1} - 1\right) \approx n\lg n + n|X|$，在 $|X| = n$ 时就是 $O(n^2)$。若点集塌缩，第 $i$ 层的点集大小是 $|X|/2^i$，单层代价 $= 2^i\left(n/2^i + |X|/2^i\right) = n + |X|$，对层数完全不敏感，一共 $\lg n$ 层，总计 $O(n\lg n)$。差别不在别处，只在「点集规模有没有跟着系数规模一起减半」这一条。
>
> 取 $n = 8$、$X$ 是八个 $8$ 次单位根，可以逐层点账。顶层：$1$ 个子问题，系数 $8$ 个、点 $8$ 个，代价约 $8+8=16$。第二层：把 $X$ 平方后只剩 $4$ 个不同的点，因为有两对根撞到同一个平方值；$2$ 个子问题，每个系数 $4$ 个、点 $4$ 个，代价 $2\times(4+4)=16$。第三层：平方再折叠，剩 $2$ 个点；$4$ 个子问题，每个系数 $2$ 个、点 $2$ 个，代价 $4\times(2+2)=16$。第四层退化成基础情形。三层几乎常数、一共 $\lg 8 = 3$ 层 —— 这就是 $O(n\lg n)$ 的手感。反例也很具体：取 $X = \{1,2,3,4,5,6,7,8\}$，平方后得 $\{1,4,9,16,25,36,49,64\}$，八个值互不相同，一对都不撞，$|X^2| = 8$，于是一层都没缩，递推退化成 $O(n^2)$。两个集合的元素个数一样，跑出来的复杂度差一个数量级，可见关键变量从来不是「点有多少个」而是「点还有多少个不同的」。
>
> 跨课程连接两处。一是 6.042J 的等价关系：在 $n$ 次单位根上定义 $z \sim w$ 当且仅当 $z^2 = w^2$。这是一个标准等价关系（自反、对称、传递三条都能直接验），它的每个等价类恰好是 $\{z, -z\}$ 两个元素，于是「平方后还剩多少个不同的点」就等于「有多少个等价类」，答案是 $|X|/2$。塌缩性在这个语言里就是一句计数：等价类个数是原来元素个数的一半。这样说比「上半圆和下半圆重合」精确，因为它同时解释了为什么必须是二对一 —— 递归减半要求每个等价类大小恒为 $2$，若某个类有 $3$ 个元素，$|X^2| = 2|X|/3$，递推就变成 $T(n) = 2T(n/2) + O(n^{1.58})$ 那种不干净的形状。二是 CLRS 里的二分搜索：那里一次比较砍掉一半搜索区间，这里一次平方砍掉一半点集，骨架同是「规模每次减半、层数就是 $\lg n$」；区别在于二分搜索的减半来自有序性（一次比较就能判定哪半边不可能），这里的减半来自代数对称性（$z$ 与 $-z$ 的平方相同），来源完全不同，可递推的形状却完全一样。
>
> 还有一处容易混淆的地方值得点破：这里的塌缩不是「近似」或「丢掉一半点」。被丢掉的点不是被忽略，而是它们的函数值可以由保留下来的点算出来 —— 因为 $A_{\mathrm{even}}$ 与 $A_{\mathrm{odd}}$ 在 $y = x^2$ 上的值同时服务于 $x$ 和 $-x$ 两个原始点。所以塌缩的本质是「两个原问题共享一个子问题的答案」，工作量因此减半，而不是信息因此丢失。反过来，若一个映射是三对一，三个原始点共享一个子答案，也能省，只是省出来的比例不再是整半，递归深度与分支数的配比会被打破。
>
> 收束一句：分治本身不产生加速，只有「子问题的输入规模真的在缩」才产生加速；单位根的全部价值就在于它把「点集减半」这个愿望变成了一个恒等式，而不是一个需要额外验证的假设。

<span style="color:#2471a3;">**[section]**</span> <span style="color:#00838f;">**单位根（Roots of Unity）**</span>

塌缩集可以通过平方根来构造。下列每个塌缩集都是取前一个集合中所有元素的平方根得到的：

1. $\{1\}$
2. $\{1, -1\}$
3. $\{1, -1, i, -i\}$
4. $\left\{1, -1, \pm \frac{\sqrt{2}}{2}(1 + i), \pm \frac{\sqrt{2}}{2}(-1 + i)\right\}$，它们都位于单位圆（unit circle）上

我们可以重复这个过程，通过在圆上找到越来越多点，把集合越做越大。这些点被称为 **$n$ 次单位根（$n$th roots of unity）**。形式化地说，$n$ 次单位根是满足 $x^n = 1$ 的 $n$ 个 $x$。这些点在复平面（complex plane）上**均匀分布**在单位圆周围（包含 1）。由 Euler 公式（Euler's Formula），这些点形如

```math
(\cos \theta, \sin \theta) = \cos \theta + i \sin \theta = e^{i\theta}, \quad \theta = 0,\ \frac{1}{n}\tau,\ \frac{2}{n}\tau,\ \ldots,\ \frac{n-1}{n}\tau \quad (\text{其中 } \tau = 2\pi)
```

当 $n = 2^\ell$ 时，$n$ 次单位根构成一个塌缩集，因为

```math
(e^{i\theta})^2 = e^{i(2\theta)} = e^{i(2\theta \bmod \tau)}
```

因此**偶数次单位根等价于 $\frac{n}{2}$ 次单位根**。

🎥 *Devadas 在视频中[用单位圆上的复数演示塌缩性]*："So e to the i tau equals 1, so going around in circles—same thing as not. ... So you can draw on this picture for every number, what is its square?"（翻译：所以 $e^{i\tau} = 1$，转一整圈等于没转。……你可以在这张图上对每个数画出「它的平方在哪」。）——把「平方 = 辐角加倍」画在单位圆上，$e^{i\theta}$ 与 $e^{i(\theta+\pi)}$ 会落到同一点，正是点集规模减半的直观来源。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注处理整讲里最容易被当成公式背诵的一块：单位根为什么长那样，以及它的平方为什么会折叠。先把 $n$th roots of unity（$n$ 次单位根）说成人话 —— 它们就是复平面上均匀分布在单位圆上的 $n$ 个点，从 $1$ 出发，每隔一个 $360^\circ/n$ 取一个，绕一圈刚好回到 $1$。
>
> Euler's formula（欧拉公式）$e^{i\theta} = \cos\theta + i\sin\theta$ 不是定义，可以推。把 $e^{i\theta}$ 按幂级数展开，把 $i$ 的幂按 $i^0=1$、$i^1=i$、$i^2=-1$、$i^3=-i$ 的循环替换掉，偶数次项收成 $\cos\theta$ 的级数、奇数次项收成 $\sin\theta$ 的级数，两边逐项相等。这里有一个实分析上的前置条件值得点出：把无穷级数拆成实部与虚部两步求和，合法性来自绝对收敛 —— 因为 $\sum |i\theta|^k/k! = e^{|\theta|} < \infty$，幂级数在任意实数 $\theta$ 上绝对收敛，所以可以任意重排、可以分开算。这一步在 100B 的语境里是要交代的，不能默认可以拆；若无绝对收敛，重排会改变和，整个推导就失去依据。
>
> 给 $n=8$ 的具体坐标。令 $\omega = e^{i\tau/8} = \cos 45^\circ + i\sin 45^\circ \approx 0.7071 + 0.7071i$，八个点依次是：$1$；$0.7071+0.7071i$；$i$；$-0.7071+0.7071i$；$-1$；$-0.7071-0.7071i$；$-i$；$0.7071-0.7071i$。它们全在单位圆上（模长都是 $1$），相邻两点的夹角都是 $45^\circ$。平方一遍看折叠：$1^2 = 1$；$(0.7071+0.7071i)^2 = i$；$i^2 = -1$；$(-0.7071+0.7071i)^2 = -i$；再往后 $-1$ 的平方回到 $1$，$-0.7071-0.7071i$ 的平方回到 $i$，$-i$ 的平方回到 $-1$，$0.7071-0.7071i$ 的平方回到 $-i$。八个点平方后只剩 $1, i, -1, -i$ 四个，每个被击中两次 —— 这就是 $|X^2| = |X|/2$ 的全部内容，没有任何额外假设。
>
> 机制一句话：复数乘法是「模长相乘、辐角相加」，所以平方就是辐角加倍。单位根按等角距排列，辐角加倍后等角距也翻倍，八个点就落成四个点；撞车的那对是辐角相差 $180^\circ$ 的点，因为 $e^{i(\theta+\pi)} = -e^{i\theta}$，而 $(-1)^2 = 1$ 把负号消掉。$\tau = 2\pi$ 的用法也是这个道理：写成 $e^{i\tau k/n}$，$k$ 从 $0$ 走到 $n-1$ 恰好是一整圈，并且 $e^{i\tau} = 1$ 让「转一整圈等于没转」这件事直接写在式子里；若改用 $\pi$ 记账，每个表达式都要额外背一个 $2$，而周期性边界条件正是这条算法全部正确性的来源，不该被符号噪音掩盖。
>
> 还有一个前提值得单独拎出来：塌缩要求 $n$ 是 $2$ 的幂。每层塌缩都要把点数除以 $2$，除到 $1$ 才停；若 $n = 12$，平方后点数从 $12$ 变 $6$，再变 $3$，下一次平方落在 $2$ 上，除不尽，最后几层必须换别的办法收尾。这就是真实库要支持任意 $n$ 时，必须同时准备混合基分解与补零两条退路的根本原因。
>
> 跨课程连接三处。Strang 线性代数里的复数乘法规则就是上面那句「模长相乘、辐角相加」，那里的写法是为了说明复数乘法等于旋转与缩放的复合，这里直接变成「平方等于角度翻倍」的几何图像。这八个点还有一个可以从零推出来的性质：它们的向量和为零，因为正八边形的重心在原点，也可以从等比级数 $\sum_{k=0}^{7}\omega^k = (\omega^8 - 1)/(\omega - 1) = 0$ 算出来，这条在后面证 $V^{-1}$ 时会原样再出现一次。第三处是 18.065 的矩阵视角：这 $n$ 个单位根就是后面 DFT 矩阵的列向量的采样点，它们选得好不好，直接决定那个矩阵是不是保长度。
>
> 收束：单位根不是什么神秘对象，它就是「把圆周 $n$ 等分」这一个几何选择的代数记账方式，而 FFT 的全部可递归性都寄生在「平方让角度加倍」这一条上。

<span style="color:#c0392b;">**FFT、IFFT 与多项式乘法（FFT, IFFT, and Polynomial Multiplication）**</span>

我们可以利用 $n$ 次单位根来改进多项式乘法算法的运行时间。该算法的基础称为**离散傅里叶变换（Discrete Fourier Transform, DFT）**。

DFT 允许在系数与采样之间变换：对 $x_k = e^{i\tau k / n}$（其中 $n = 2^\ell$）计算 $A \to A^{*} = V \cdot A$，其中 $A$ 是系数集合，$A^{*}$ 是得到的采样。单个项为

```math
a^{*}_j = \sum_{j=0}^{n-1} e^{i\tau jk/n} \cdot a_j
```

> <span style="color:#7f8c8d;">[译注] 原文此处下标不严谨：左侧自由下标为 $j$，求和下标也为 $j$，指数里却出现未定义的 $k$。标准写法应为 $a^{*}_k = \sum_{j=0}^{n-1} e^{i\tau jk/n} a_j$，即第 $k$ 个采样值是各系数 $a_j$ 用「频率 $k$ 的根 $e^{i\tau k/n}$」加权求和。译文保留原式以便对照，读者按标准式理解即可。</span>

<span style="color:#2471a3;">**[section]**</span> <span style="color:#00838f;">**快速傅里叶变换（Fast Fourier Transform, FFT）**</span>

FFT 是用于 DFT 的 $O(n \lg n)$ 分治算法，由 **Gauss** 大约在 **1805** 年使用，后由 **Cooley 与 Tukey** 于 **1965** 年推广。Gauss 用该算法确定周期性小行星轨道（periodic asteroid orbits），而 Cooley 与 Tukey 用它从离岸读数中**探测苏联核试验**（detect Soviet nuclear tests）。

FFT 的一个实用实现是 **FFTW**，由 MIT 的 **Frigo 与 Johnson** 描述。该算法常被直接做成硬件实现（implemented directly in hardware），用于固定的 $n$。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注往前看一步：为什么一个 $1965$ 年才被重新发表的算法，其实 $1805$ 年就已经写在纸上了；以及 FFTW 这个名字背后到底在优化什么东西。先把事实钉住：Gauss 在 $1805$ 年的一份未发表手稿里已经写出了等价的分治递推（混合基、带旋转因子的形式），用途是从少量观测点确定小行星轨道；Cooley 与 Tukey 在 $1965$ 年于《Mathematics of Computation》第 $19$ 卷 $297$ 至 $301$ 页重新发表了同一族算法。中间还夹着 Danielson 与 Lanczos 在 $1942$ 年的版本，所以这至少是一次四重独立发现。
>
> 这一百六十年不是「没人想到」，而是「想到了没有用处」。手工计算时代 $n$ 最多几十，$n^2$ 与 $n\lg n$ 的差别小到不值得写一篇论文；机器一出现，$n$ 变成 $10^5$ 到 $10^7$，同样两条曲线之间就隔着一堵数量级的墙。Cooley 与 Tukey 的动机也很硬：当时要在大量台站的时序里找出地下核试验的信号，台站多、序列长，按定义直接算根本算不完。这给出一条一般性的判断准则 —— 一个算法的价值不只由它的渐近阶决定，还由「当时的 $n$ 落在两条曲线的哪一段」决定。
>
> 把这条曲线算成具体数字。取 $n = 2^{20} = 1\,048\,576$。朴素做法需要 $n^2 \approx 1.1\times 10^{12}$ 次复数乘法，每次复数乘法约等于 $4$ 次实数乘法加 $2$ 次加法，折算成 $6.6\times 10^{12}$ 次浮点运算；按 $10$ GFLOP/s 的有效算力，约 $660$ 秒，也就是十一分钟。FFT 需要 $(n/2)\lg n = 524288 \times 20 \approx 1.05\times 10^{7}$ 次 butterfly（蝶形运算），旋转因子预存好之后每次约 $10$ 次浮点运算，折算成 $1.05\times 10^8$ 次，约 $0.01$ 秒。比值约 $6\times 10^{4}$。这个数字的意义是：$n$ 到十万量级以后，FFT 让「实时处理」从不可能变成日常；而 $n$ 只有几十的时候，两条曲线在纸上是分不出胜负的。
>
> FFTW 的新意不在渐近阶，而在「同一族分治里挑哪一个」。它有一个 planner（规划器），在真正算之前先在小规模上试跑几种分解方案，量测哪一种最快，再把方案复用到整个数组；它还在安装时生成大量固定小长度的特化核，也就是所谓的 codelet。为什么要这么干？因为 $n = 2^{20}$ 的复数数组按双精度算是 $16$ MB，远超 L2 的几百 KB，必然一路落到内存；不同的递归次序对应完全不同的访存模式，最快的那个随 CPU 的 cache（缓存）层次而变，写死在代码里的常数方案没法跨机器最优。这就是 CSAPP 第六章那套「存储层次决定实际速度」的直接应用，也是「程序性能来自特例化」在库层面的体现。
>
> 跨课程连接：CSAPP 第六章给了层级的具体数字：L1 几十 KB、L2 几百 KB、L3 几 MB，可以直接用来解释为什么 FFTW 必须自适应 —— 工作集一旦超过 L2，命中率就由递归次序决定，而不是由算法的渐近阶决定；区别在于 CSAPP 讲的是怎么为已知的 cache 参数写代码，FFTW 走的是相反的路：不假设参数，让程序在运行时自己测出来。另一条线是本课程讲外部存储与缓存无关算法的那两讲，那里把「不依赖具体缓存大小仍然最优」提成一条设计目标，FFTW 的递归分治正好是这个目标在 FFT 上的实例。还有一点值得记住：这场重新发现的历史本身就是一条教训 —— 同一个算法在纸上是「浪费」、在机器上是「必需」，所以判断一个算法值不值得学，必须把它放回它要处理的 $n$ 的量级里。
>
> 收束：历史告诉我们算法的价值有外部条件，FFTW 告诉我们同一族算法内部还剩多少常数可以榨；两件事都在说「$O$ 记号之外还有一层现实」。

<span style="color:#2471a3;">**[section]**</span> <span style="color:#00838f;">**逆离散傅里叶变换（Inverse Discrete Fourier Transform, IDFT）**</span>

逆离散傅里叶变换是把「已乘好的采样」还原成多项式系数的算法。变换形式为

```math
A^{*} \to V^{-1} \cdot A^{*} = A
```

要计算它，我们需要找出 $V^{-1}$，而 $V^{-1}$ 事实上有一个非常漂亮的结构。

<span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b;">**Claim 1（声明 1）.**</span>

```math
V^{-1} = \frac{1}{n} \overline{V}
```

其中 $\overline{V}$ 是 $V$ 的复共轭（complex conjugate）。^1

> <span style="color:#7f8c8d;">^1 回忆：$p + qi$ 的复共轭是 $p - qi$。</span>

<span style="color:#c0392b;">**IDFT 证明（续）**</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 我们断言 $P = V \cdot \overline{V} = nI$：

```math
\begin{aligned}
p_{jk} &= (\text{第 } j \text{ 行 of } V) \cdot (\text{第 } k \text{ 列 of } \overline{V})\\
&= \sum_{m=0}^{n-1} e^{ij\tau m/n} \overline{e^{ik\tau m/n}}\\
&= \sum_{m=0}^{n-1} e^{ij\tau m/n} e^{-ik\tau m/n}\\
&= \sum_{m=0}^{n-1} e^{i(j-k)\tau m/n}
\end{aligned}
```

现在，若 $j = k$，则 $p_{jk} = \sum_{m=0}^{n-1} 1 = n$。否则它构成一个**等比级数**（geometric series）：

```math
p_{jk} = \sum_{m=0}^{n-1} \left(e^{i(j-k)\tau/n}\right)^m = \frac{\left(e^{i\tau(j-k)/n}\right)^n - 1}{e^{i\tau(j-k)/n} - 1} = 0
```

因为 $e^{i\tau} = 1$。因此 $V^{-1} = \frac{1}{n}\overline{V}$，因为 $V \cdot \overline{V} = nI$。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要把一个「看起来要解 $n^2$ 个方程」的问题，变成一次按行做内积的验算。Claim 1 说的是 $V^{-1} = \frac{1}{n}\overline{V}$，等价于 $V\overline{V} = nI$；也就是说，只要证明「不同频率的两行互相垂直、同一行与自己的共轭行内积等于 $n$」，逆矩阵就等于随手写出来，一次 Gaussian elimination（高斯消元）都不用做。
>
> 机制要逐句拆。$V$ 的第 $j$ 行是 $\left(1, \omega^{j}, \omega^{2j}, \ldots\right)$，第 $k$ 行是 $\left(1, \omega^{k}, \omega^{2k}, \ldots\right)$，其中 $\omega = e^{i\tau/n}$。$\overline{V}$ 的第 $k$ 行把每个元素取共轭，等价于把 $\omega$ 换成 $\omega^{-1}$。于是乘积的第 $(j,k)$ 个元素是 $\sum_{m=0}^{n-1}\omega^{jm}\cdot\omega^{-km} = \sum_{m=0}^{n-1}\left(\omega^{j-k}\right)^m$。这一步是全部技巧所在：两行的内积被压成了一条等比级数，公比只依赖 $j-k$。
>
> 分两种情形。若 $j = k$，公比是 $1$，$n$ 项全为 $1$，和为 $n$ —— 这给出对角线上的那个 $n$。若 $j \ne k$，则 $0 < |j-k| < n$，公比 $r = \omega^{j-k} \ne 1$，用有限等比级数求和得 $\sum_{m=0}^{n-1} r^m = (r^n - 1)/(r - 1)$；分子 $r^n = \omega^{n(j-k)} = e^{i\tau(j-k)} = 1$，所以分子为零；分母 $r - 1 \ne 0$，所以整个和为零。这里必须检查「分母不为零」那一步：若 $j - k$ 是 $n$ 的倍数，公比就退化成 $1$，公式失效 —— 而 $j$、$k$ 都落在 $0$ 到 $n-1$ 里，只有 $j = k$ 会让差成为 $n$ 的倍数，已经被第一种情形接走。若反过来假定分母非零、却忘了排除 $j-k = \pm n$，证明会在边界上漏掉一整类情形，而这类边界遗漏恰好是这类证明最常见的失败方式。
>
> 手验 $n=4$、$\omega = i$ 的一个非对角元素。第 $0$ 行是 $(1,1,1,1)$，$\overline{V}$ 的第 $1$ 列是第 $1$ 行取共轭，即 $(1, -i, -1, i)$。内积 $= 1 + (-i) + (-1) + i = 0$。再验对角元素：第 $0$ 行与自己的共轭行内积 $= 1+1+1+1 = 4 = n$。所以 $V\overline{V} = 4I$，$V^{-1} = \frac{1}{4}\overline{V}$，与声明一致。注意这里的 $1/n$ 不是凑出来的：每行与自身的内积是 $n$，正规化因子自然就是 $1/n$。
>
> 这条证明还顺手给出一个能在纸上验证的结构事实。令 $F = V/\sqrt{n}$，那么 $F\overline{F}^{\mathsf{T}} = I$，即 $F$ 保持向量的欧氏长度不变。再算 $F^2$：$(V^2)_{jk} = \sum_m \omega^{m(j+k)}$，这个和当且仅当 $j + k \equiv 0 \pmod n$ 时为 $n$、否则为 $0$，所以 $V^2 = nP$，其中 $P$ 是把下标 $k$ 送到 $-k$ 的反序置换矩阵，从而 $F^2 = P$。于是 $F^4 = P^2 = I$。用 $n=4$ 验一遍：$V^2$ 的第 $(0,0)$ 项是 $4$，第 $(0,3)$ 项也是 $4$，其余为 $0$ —— 正是把 $0,1,2,3$ 送到 $0,3,2,1$ 的那个矩阵，平方两次当然回到恒等。这条 $F^4 = I$ 值得单独记住，因为它是后面「同一个变换做四次就回到原点」这类结论的根，也是把 DFT 看成四分之一圈旋转的形式化依据。
>
> 跨课程连接：Strang 线性代数里，一组向量两两垂直、长度相同，就能立刻写出逆矩阵是「转置除以长度的平方」，这里把转置换成共轭转置、把长度平方换成 $n$，公式形状一模一样；区别在于实数内积不需要共轭，复数内积必须带共轭，否则 $(1,i)$ 与自己的内积会是 $1 + i^2 = 0$，「垂直于自己」这种荒谬结论就会出现 —— 共轭正是为了修正这一点。第二处是 6.042J 的有限等比级数：那条公式在那里是组合计数工具，在这里变成「整数频率互相垂直」的依据，同一行字，两种用途。
>
> 收束：这个证明的模板可以抽象成一句 —— 要证 $M^{-1} = cM'$，不必列方程，只需算一行字的内积，把每个元素化成同一条几何级数，再分「公比为 $1$」与「公比非 $1$」两种情形；同一模板后面还会用来验证各种正交表。

这个声明说明：**逆离散傅里叶变换等价于离散傅里叶变换**，只是把 $x_k$ 从 $e^{ik\tau/n}$ 换成它的复共轭 $e^{-ik\tau/n}$，并把结果向量除以 $n$。IFFT 的算法与 FFT 类似，结果是 $O(n \lg n)$ 的 IDFT 算法。

🎥 *Devadas 在视频中[强调 IFFT 的惊人之处]*："Very cool because what this tells us is we run exactly the same algorithm and do exactly the same transformation. If we want to do the inverse, we can actually just use V, but with a different choice of x_k. Namely, for the inverse, we just take the complex conjugate ... and then divide the whole thing by n."（翻译：非常酷的一点是，这告诉我们：我们运行完全相同的算法、做完全相同的变换。如果想要做逆变换，实际上只需用同一个 $V$，但换一组 $x_k$ 的选择——对逆变换，我们只需取复共轭……再整体除以 $n$。）——**一个算法、两种模式**，这正是「同一个分治核心 + 参数微调」的复用美学。

<span style="color:#2471a3;">**[section]**</span> <span style="color:#00838f;">**快速多项式乘法（Fast Polynomial Multiplication）**</span>

为了计算两个多项式 $A$ 与 $B$ 的乘积，我们执行以下步骤：

1. 计算 $A^{*} = \mathrm{FFT}(A)$ 与 $B^{*} = \mathrm{FFT}(B)$，把 $A$、$B$ 从系数向量转换为采样表示。
2. 在采样表示下用线性时间计算 $C^{*} = A^{*} \cdot B^{*}$：逐点相乘 $C^{*}_k = A^{*}_k \cdot B^{*}_k$（对所有 $k$）。
3. 计算 $C = \mathrm{IFFT}(C^{*})$，得到最终解的向量表示。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答两件事：三段式算法为什么正好是这个顺序，以及中间那步「逐点相乘」之前为什么必须先做 zero-padding（零填充）。整个流程是 coefficient（系数）到 sample（采样）、在采样域逐点乘、再 inverse（逆）回来，三步各自解决一个不同的问题，少一步就错。
>
> 顺序的必然性来自「乘法在哪一步最便宜」。系数域里乘法是卷积，$O(n^2)$；采样域里乘法是 $n$ 个独立的标量乘，因为 $C(x_i) = A(x_i)B(x_i)$ 对每个点单独成立，$O(n)$。所以策略是把乘法搬到采样域去做，代价是两次搬运；搬运本身要 $O(n\lg n)$，于是总账是 $O(n\lg n) + O(n) + O(n\lg n)$，仍然是 $O(n\lg n)$。三段里没有任何一段可以被省略：不做第一次变换，乘法还是 $O(n^2)$；不做逐点乘，什么也没算；不做逆变换，拿到的是一堆采样值而不是系数。
>
> 这里真正需要小心的是「采样域够不够大」。具体算一次踩坑：还是 $A = (1,2,3)$、$B = (4,5)$，真乘积 $C = (4,13,22,15)$，次数为 $3$，一共 $4$ 个系数。如果只在 $n = 3$ 个点上做变换（比如用三个三次单位根），采样域只给了 $3$ 个约束，而结果需要 $4$ 个系数 —— 情况就变成「三个点定不住一个三次多项式」。实际算出来会得到 $C$ 对 $x^3 - 1$ 取模的结果，也就是把 $c_3 x^3$ 那一项折回常数项：$c_0$ 变成 $4 + 15 = 19$，$c_1$、$c_2$ 不变，得到 $(19, 13, 22)$。这个错不会报错、不会崩，只会静默给出另一个多项式 —— 这正是 cyclic convolution（循环卷积）混叠的典型症状。
>
> 正确做法是补零到 $n \ge 4$（实际取 $2$ 的幂，即 $4$）：把 $A$、$B$ 都补成长度 $4$ 的向量，在四个四次单位根上变换，逐点乘，逆变换回 $4$ 个系数，与手算的 $(4,13,22,15)$ 一致。这条规则可以写成一句话：结果次数是 $2n-2$，所以点数至少要是 $2n-1$，取 $2$ 的幂就变成「补到不小于 $2n-1$ 的最小的 $2$ 的幂」；这一步只会把数组长度最多翻一倍，不影响渐近阶，但它决定算法是对的、还是悄悄错的。
>
> 跨课程连接三处，都用你已经在用的东西。一是 6.042J 的生成函数：那里用乘法把两个数列的卷积「卷」成新数列，用来数分法与组合的方案数；FFT 就是快速乘这两个生成函数的工具，区别在于生成函数那边常常只关心前几项系数、可以截断，这里要求完整乘积，必须补零到最后一项。二是 CLRS 第 30 章：它把递归版与一个迭代版并置，迭代版用 bit-reversal permutation（位反转置换）把输入重排成递归到达的次序，再跑三层循环；与本讲的递归写法数学上完全等价，区别是迭代版把递归栈换成了数组下标运算，常数更小但预处理多一步。三是 CSAPP 第六章：位反转那一步的访存模式非常不友好，几乎每次都跳到很远的位置，所以真实实现会把这一步和第一层蝶形合起来做，或者干脆分块拷贝 —— 这就是「算法一样、常数差十倍」的具体来源。
>
> 收束：三段式的骨架是「换一个域去做那件便宜的事」，而补零是这条骨架的准入条件 —— 点数不够，换域换出来的就是另一个问题的答案。

<span style="color:#c0392b;">**应用（Applications）**</span>

傅里叶（频率）空间（Fourier / frequency space）有大量应用。多项式 $A^{*} = \mathrm{FFT}(A)$ 是复值（complex）的，其中幅值（amplitude）$|a^{*}_k|$ 表示频率为 $k$ 的信号（signal）的幅度，而 $\arg(a^{*}_k)$（二维向量的角度）表示该信号的**相位偏移（phase shift）**。例如，这个视角对音频处理（audio processing）特别有用，如 Adobe Audition、Audacity 等所使用的：

- **高通滤波器（High-pass filters）**：把高频（high frequencies）置零
- **低通滤波器（Low-pass filters）**：把低频（low frequencies）置零
- **音高移位（Pitch shifts）**：平移频率向量
- **用于 MP3 压缩（MP3 compression）**等

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注把 FFT 从「多项式乘法的加速器」换一个身份看：它是一台把 time domain（时域）里的信号搬到 frequency domain（频域）的机器，而这一页列的所有应用，本质都是「在频域里把某些基的系数改掉，再搬回来」。
>
> 机制先讲清楚。$n$ 个采样点可以看成 $n$ 个基向量 $e^{i\tau kt/n}$ 的加权和，权重就是 $a^{*}_k$；第 $k$ 个基向量在一个周期里转 $k$ 圈，所以 $k$ 越大振荡越快。DFT 做的事就是把这组权重解出来：$|a^{*}_k|$ 是这条分量的 amplitude（振幅），$\arg a^{*}_k$ 是它的 phase shift（相位偏移）。于是「置零高频」与「让声音变闷」是同一句话的两种说法 —— 把 $k$ 大的那批系数置零，等于删掉振荡最快的那些基向量，剩下的自然只剩慢变化。这就是 low-pass filter（低通滤波器）的实现；反过来置零低频就是 high-pass filter（高通滤波器）。这种做法把分辨率控制到了单个频点，而不是靠一个固定形状的卷积核去抹。
>
> 给能直接代入的数字。采样率 $f_s = 44100$ Hz，取 $n = 1024$ 个样本做一次变换，频点间隔是 $\Delta f = f_s / n = 44100/1024 \approx 43.07$ Hz，也就是说第 $k$ 个 bin（频点）对应 $k \times 43.07$ Hz。想做一个 $3000$ Hz 以上的高通，就是保留 $k \ge 3000/43.07 \approx 69.6$ 的项，即把 $k = 0$ 到 $69$ 全部置零。若把窗长换成 $n = 2^{20}$，$\Delta f = 44100/1048576 \approx 0.042$ Hz，频率分辨率提高了一千倍，代价是这一次变换要覆盖 $1048576/44100 \approx 23.8$ 秒的信号 —— 频率分辨率与时间分辨率是一对必须交换的量，不能同时要。
>
> 再看「为什么值得换到频域做滤波」。设信号长 $n = 10^{6}$ 个点、滤波器长 $m = 4096$。直接在时域做卷积要约 $n \cdot m = 4.1\times 10^{9}$ 次乘加；换到频域，三次变换各要约 $(n/2)\lg n = 10^{7}$ 次蝶形运算，再加 $10^{6}$ 次逐点乘，量级约 $3\times 10^{7}$，差了两个数量级。这也解释了另一个方向的取舍：$m$ 只有几十的时候，频域路线的固定开销（三次变换）反而更贵，短滤波器就该老老实实在时域扫。
>
> MP3 那一行的机制要说准一点：MP3 的主体变换是 MDCT，一种在相邻块之间重叠的余弦变换，好处是块边界不会出现突变；编码器还会并行跑 FFT 做心理声学分析，算出每个频点上「人耳听不出来」的量化精度下限，再按这个下限砍位数。所以它用的是「变换加听觉模型」，而不是单纯的频域截断 —— 这正是同等码率下它比朴素截断好听的原因；JPEG 走的是同一套逻辑，只把 MDCT 换成 DCT。
>
> 往前看两步。一是 sparse Fourier transform（稀疏傅里叶变换）：如果信号在频域只有 $k$ 个非零项且 $k \ll n$，那 $n\lg n$ 就买多了，$2012$ 年的一族算法用亚线性数量的采样把主频找出来，前提是稀疏性假设成立。二是卷积神经网络里的频域卷积：把卷积核与特征图都变到频域、逐点相乘再变回来，在核较大的层上能省下可观的时间，代价是多两次变换与额外的内存。
>
> 跨课程连接：18.065 里把矩阵分解成特征向量与特征值的谱形式，频谱就是同一件事在「循环移位」这个操作上的版本 —— 那里追求把矩阵对角化，这里追求把卷积对角化，而两者的载体都是「换一组基之后结构变简单」。CSAPP 里的音频编码、图像压缩在系统层面是同一套流程，那里你看到的是格式与缓冲，这里看到的是变换本身。
>
> 收束：这一页的四行应用只是同一句话的四个例句 —— 在频域里，滤波器就是一支把不需要的频率划掉的笔。
