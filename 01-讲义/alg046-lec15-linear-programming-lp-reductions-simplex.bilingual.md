<span style="color:#c0392b">**讲次 15（Lecture 15）：线性规划（Linear Programming）**</span> <span style="color:#7f8c8d;">（Spring 2015，2015 春季学期）</span>

线性规划（Linear programming, LP）是在由**线性关系**表示的若干要求之下，达到**最优结果（optimum outcome）**的一种方法。更精确地说，LP 可以求解这样的问题：在若干**线性约束（linear constraints）**下，**最大化或最小化一个线性目标函数（linear objective function）**。

一般而言，LP 的**标准形式（standard form）**由以下部分组成：
- **变量（Variables）**：$x = (x_1, x_2, \ldots, x_d)^T$
- **目标函数（Objective function）**：$c \cdot x$
- **不等式约束（Inequalities / constraints）**：$Ax \le b$，其中 $A$ 是一个 $n \times d$ 矩阵

并在约束以及 $x \ge 0$ 下**最大化**目标函数。

LP 有许多不同的应用，例如流（flow）、最短路（shortest paths），甚至政治（politics）。本讲将覆盖 LP 的不同例子，并给出求解它们的算法；我们还将学习如何把任意 LP 转化为标准形式。

<span style="color:#c0392b">**1. 线性规划的实例：政治（Examples of Linear Programming: Politics）**</span>

在这个例子中，我们将研究如何通过竞选（campaign）来赢得一场选举。一般而言，有 $n$ 个**人口群体（demographics）**，每个群体有 $p_i$ 人，还有 $m$ 个选民关心的**议题（issues）**。给定「每花一美元在支持某个议题的广告上，能获得多少张选票」的信息，我们怎样才能**通过在所有人群体中确保多数（majority）**来保证获胜？^1

具体地，考虑表 1 中所示的 3 个人口群体、4 个议题的例子。要**在所有群体中保证多数**，我们**最少**需要花多少钱？

令 $x_1, x_2, x_3, x_4$ 分别表示花在每个议题上的美元数。我们现在可以把该问题表述为一个 LP 问题：

```math
\begin{aligned}
\text{Minimize} \quad & x_1 + x_2 + x_3 + x_4 \\
\text{Subject to} \quad
-2x_1 + 8x_2 + 0x_3 + 10x_4 &\ge 50{,}000 \quad \text{(Urban Majority)} \tag{1} \\
5x_1 + 2x_2 + 0x_3 + 0x_4 &\ge 100{,}000 \quad \text{(Suburban Majority)} \tag{2} \\
3x_1 - 5x_2 + 10x_3 - 2x_4 &\ge 25{,}000 \quad \text{(Rural Majority)} \tag{3} \\
x_1, x_2, x_3, x_4 &\ge 0 \quad \text{(Can't unadvertise)} \tag{4}
\end{aligned}
```

> <span style="color:#7f8c8d;">^1 我们将假设：在不同议题上做广告所获得的选票是**互不相交（disjoint）**的。</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这个竞选例子的表是「**每人美元选票表**」——表中数字是「每花 1 美元在广告上，能从该人口群体中拉来的选票数」，**可以是负数**（比如在乡村推广枪支管制 Gun Control，反而会丢选票，所以约束 (3) 里 $x_2$ 的系数是 $-5$）。注意三个约束的右侧 $50{,}000 / 100{,}000 / 25{,}000$ **恰好是各群体人口的一半**（城市 100,000、郊区 200,000、乡村 50,000），这正是「多数 majority」的数学化：约束要求「在该群体拿到的选票 $\ge$ 人口的一半」。于是「保证赢得选举」就变成了「在三个线性不等式下最小化总广告费」——一个纯粹的优化问题。这个例子还演示了 LP 作为**通用建模语言**的价值：最大流、最短路（本讲第 4 节）乃至政治竞选的分配问题，全都能装进同一个「线性目标 + 线性约束」的框架。这与你在 6.006/CLRS 里见过的**归约（reduction）**思想一脉相承：把五花八门的问题**统一翻译**成标准形式，交给同一个求解器。

<span style="color:#c0392b">**1.1 最优性证书（Certificate of Optimality）**</span>

虽然我们还没有给出求解这个问题的算法，但**给定一个解**，我们可以借助一个恰当的**证书（certificate）**来验证该解是最优的。例如，

```math
x_1 = \frac{2050000}{111}, \quad
x_2 = \frac{425000}{111}, \quad
x_3 = 0, \quad
x_4 = \frac{625000}{111}
```

是这个问题的一个解，且

```math
x_1 + x_2 + x_3 + x_4 = \frac{3100000}{111}
```

现在考虑下面的方程（证书）：

```math
\frac{25}{222} \cdot (1) + \frac{46}{222} \cdot (2) + \frac{14}{222} \cdot (3)
= x_1 + x_2 + \frac{140}{222} x_3 + x_4
```

```math
\ge \frac{25}{222} \cdot 50000 + \frac{46}{222} \cdot 100000 + \frac{14}{222} \cdot 25000
= \frac{3100000}{111}
```

```math
\Rightarrow \quad x_1 + x_2 + \frac{140}{222} x_3 + x_4 \ge \frac{3100000}{111}
```

我们还知道 $x_1 + x_2 + x_3 + x_4 \ge x_1 + x_2 + \frac{140}{222} x_3 + x_4$（因为 $x_3 \ge 0$ 且 $\frac{140}{222} < 1$）。因此，给定的解是这个问题的一个**最优解（optimal solution）**。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这张表与 LP 约束之间有一处**原讲义的笔误**，值得警惕：表中「汽油税/乡村」一格印的是 **+2**，但约束 (3)（乡村多数）写的是 $3x_1 - 5x_2 + 10x_3 - 2x_4 \ge 25{,}000$，即 $x_4$ 的系数是 **$-2$**。以证书为准即可判定真伪：把 $\frac{25}{222}(1) + \frac{46}{222}(2) + \frac{14}{222}(3)$ 展开，$x_4$ 的系数是 $\frac{25 \cdot 10 + 46 \cdot 0 + 14 \cdot (-2)}{222} = \frac{250 - 28}{222} = \frac{222}{222} = 1$——**只有用 $-2$ 才能凑出系数 1**，从而让等式左边恰好等于 $x_1 + x_2 + \frac{140}{222}x_3 + x_4$。所以表格那一格应为 $-2$，约束 (3) 才是权威版本。这提醒我们：讲义表格与公式冲突时，**用「可验证的数学对象」（这里的证书恒等式）来仲裁**，而不是盲信排版。

> <span style="color:#1e8449;">**[note] Note（译者注，费曼式）:**</span> 所谓**最优性证书**，就是一段「足够短的、能立刻证明答案不能再好」的算式。直觉是这样：你手里每个约束都是一条「**规则**」——比如城市约束说「花的钱在四议题上加权后至少换 50,000 票」。如果把几条规则**按非负权重相加**，得到的新规则依然成立（约束的加权和还是约束）。现在精心挑选权重 $\left(\frac{25}{222}, \frac{46}{222}, \frac{14}{222}\right)$，使加权后的新规则恰好变成「$x_1 + x_2 + \frac{140}{222}x_3 + x_4 \ge \frac{3100000}{111}$」——一个对**任何可行解**都成立的下界。而你手里的解总花费恰为 $\frac{3100000}{111}$，达到了这个下界 → **它不可能更优了**。这套「加权组合约束 → 逼出下界 → 解达到下界」正是第 2 节**对偶（duality）**的雏形：那些「魔法权重」就是**对偶变量（dual variables）**。背后更深的定理是 **Farkas 引理（Farkas' lemma）**——一个「二选一定理（theorem of the alternative）」：要么原系统可行，要么存在这样一组正权重制造出矛盾；它是对偶理论的地基（Gale-Kuhn-Tucker 1951 的标准表述）。🎥 *Devadas 在视频里点破这不是巧合*："what just happened wasn't a coincidence. You can do this all the time."（翻译：刚才发生的事不是巧合，你可以随时这么做。）——对任意 LP，都存在对应某一组系数的最优性短证书。

<span style="color:#c0392b">**2. 线性规划对偶（Linear Programming Duality）**</span>

上一节给出的**短证书（short certificate）**并非巧合，而是 LP 问题**对偶性（duality）**的一个推论。对每个形如

```math
\text{Maximize} \quad c \cdot x \qquad \text{Subject to} \quad Ax \le b, \; x \ge 0
```

的**原始 LP（primal LP）**问题，都存在一个等价的**对偶 LP（dual LP）**问题

```math
\text{Minimize} \quad b \cdot y \qquad \text{Subject to} \quad A^T y \ge c, \; y \ge 0
```

LP 的这个性质可以用来证明许多重要定理。例如，**最大流最小割定理（max-flow min-cut theorem）**可以通过把最大流问题表述为原始 LP 问题来证明。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 对偶变换是「**翻个身 + 转置**」的对称操作：原始变量的个数 = 对偶约束的个数，原始约束的个数 = 对偶变量的个数；最大化变成最小化，系数向量 $c$ 与右侧向量 $b$ 互换位置，矩阵 $A$ 转置成 $A^T$，不等号反向。🎥 *Devadas 的概括很形象*："the dual LP flips everything. And it's not just negation, but transposed, and the actual variables also swap functionalities."（翻译：对偶 LP 把一切都翻转了。不只是取负，还有转置，变量之间还交换了角色。）**弱对偶（weak duality）**说：任意对偶可行解的目标值都是原始最优值的一个界（本讲政治例子的证书正是在构造这个界）；**强对偶（strong duality）**说：若原始有最优解，则对偶也有最优解，且**两者最优值相等**。你在讲次 13 的网络流里已经见过弱/强对偶的**流版本**：任何流 ≤ 任何割容量（弱），最大流 = 最小割（强）——本节的 $A^T$ 对偶正是那一套论证的**矩阵化推广**。经济解释（**影子价格 shadow prices**）也很直观：原始是「给定原材料 $b$，怎么生产价值 $c \cdot x$ 最大」；对偶变量 $y_j$ 是「单位原材料 $j$ 的影子价格」，对偶目标 $b \cdot y$ 是「按影子价格买入全部原材料的成本」——强对偶即「最优利润 = 最优采购成本」。

<span style="color:#c0392b">**3. 化为标准形（Converting to Standard Form）**</span>

一个问题的**自然 LP 表述**可能并不是标准 LP 形式。在这些情况下，我们可以用以下规则把问题转化为标准 LP 形式，而**不影响答案**：

- **最小化目标函数**：把系数取负，再最大化。
- **变量 $x_j$ 没有非负约束**：用 $x_j' - x_j''$ 替换 $x_j$，并令 $x_j', x_j'' \ge 0$。
- **等式约束**：拆成两个不同的约束；$x = b \Rightarrow x \le b,\; x \ge b$。
- **大于等于约束**：系数取负，转化为小于等于约束。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这四条规则就是「**把任何 LP 编译成标准形**」的翻译表：目标方向、变量范围、等式、不等式方向，四类「方言」各有一条到标准形的语法糖。其中**自由变量替换** $x_j = x_j' - x_j''$ 是唯一需要动脑子的技巧——一个可正可负的变量被拆成两个非负变量之差，而**代价**是变量个数翻倍（后面的单纯形会因此多出 $n$ 个变量）。这四条规则配合第 4 节的建模能力，让 LP 成为一门名副其实的「**通用优化语言**」：任何线性规划问题都能先归一化到标准形，再交给统一的求解器。这与你在 6.006 学过的归约思想完全同构——**把问题翻译成标准格式，比针对每个问题发明专门算法省力得多**。

<span style="color:#c0392b">**4. 表述 LP 问题（Formulating LP Problems）**</span>

在本节中，我们将简要描述如何把本课之前见过的某些问题表述为 LP 问题。一旦我们有了 LP 表述，就可以按第 3 节所述把问题转化为标准形式。

<span style="color:#c0392b">**4.1 最大流（Maximum Flow）**</span>

我们可以把最大流问题建模为**流量之和的最大化**，并受一些**刻画流量不同性质**的约束。给定 $G(V, E)$、每条 $e \in E$ 的容量 $c(e)$、源 $s$ 与汇 $t$：

```math
\begin{aligned}
\text{Maximize} \quad & \sum_{v \in V} f(s, v) \\
\text{Subject to} \quad
f(u, v) &= -f(v, u) \quad \forall u, v \in V \quad \text{(skew symmetry, 反对称)} \\
\sum_{v \in V} f(u, v) &= 0 \quad \forall u \in V - \{s, t\} \quad \text{(conservation, 流量守恒)} \\
f(u, v) &\le c(u, v) \quad \forall u, v \in V \quad \text{(capacity, 容量)}
\end{aligned}
```

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 三条约束把讲次 13 里**流（flow）的定义**逐字翻译成了线性不等式：反对称（反向流量取负）、守恒（除源汇外净流出为零）、容量上界。目标 $\sum_{v \in V} f(s, v)$ 正是流价值 $|f| = f(s, V)$。这说明 LP 是网络流理论的**声明式（declarative）**表述——你只需「描述问题」，求解器负责找出答案；而 Ford-Fulkerson / Edmonds-Karp（讲次 13、14A）是**过程式（procedural）**的专门算法。🎥 *Devadas 在开场就点明了这一点*："You could have just run the linear program with an appropriate input derived from the flow network... We wouldn't have had to go through all of that pain."（翻译：只要把流网络导出的合适输入丢给线性规划求解器就行……我们本不必经历推导最大流算法的那么多痛苦。）而**对偶视角**给出了理论红利：最大流 LP 的对偶恰是最小割 LP，**强对偶即最大流最小割定理**——上一节说「对偶可证 max-flow min-cut」，这里就是那个证明的落点。

<span style="color:#c0392b">**4.2 最短路（Shortest Paths）**</span>

我们可以把最短路问题建模为**从某节点出发的所有距离之和的最小化**。注意：这个和**只在所有距离都被最小化时**才达到最小。给定 $G(V, E)$、每条 $e \in E$ 的权重 $w(e)$，以及源 $s$：

```math
\begin{aligned}
\text{Maximize} \quad & \sum_{v \in V} d(v) \\
\text{Subject to} \quad
d(v) - d(u) &\le w(u, v) \quad \forall u, v \in V \quad \text{(triangular inequality, 三角不等式)} \\
d(s) &= 0
\end{aligned}
```

注意上面是**最大化**，所以所有距离不会都变成 0。这个 LP **无解，当且仅当**存在从 $s$ 可达的**负权环（negative weight cycle）**。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这一小节是整讲最优雅的「一句话建模」之一，值得吃透。约束 $d(v) - d(u) \le w(u, v)$ 即 $d(v) \le d(u) + w(u, v)$——这正是你在 6.006 的 Bellman-Ford / Dijkstra 里反复用到的**松弛（relaxation）**不等式。注意原文开头一句「把最短路建模为**最小化**所有距离之和」是**又一处原讲义笔误**：下面的 LP 框与末尾「Note the maximization above」都明确写着**最大化**，应以 Maximize 为准（把「最小化」读成「最大化」后，本段论证才自洽）。把「最大距离」作为目标看起来反直觉（最短路不是该最小化吗？），但陷阱在于：如果最小化 $\sum d(v)$，全部 $d(v) = 0$ 就满足所有三角不等式，得到无意义解。**最大化**则把每个 $d(v)$ 向上顶到三角不等式允许的**最紧上界**，即 $d(v) = \operatorname{dist}(s, v)$（从 $s$ 到 $v$ 的真实最短路长）——松弛到极限就自然收敛到最短距离。而「无解 ⟺ 存在可达负权环」也正是 Bellman-Ford 检测负环的判据：若存在负环，沿环把三角不等式相加得到 $0 \le$ 负值，矛盾；反过来没有负环时，最短路距离本身就是一个可行解。这个「可行域 = 所有可行势函数（potential）」的解读，与讲次 11 全源最短路 / 差分约束的论证一脉相承。

<span style="color:#c0392b">**5. LP 的算法（Algorithms for LP）**</span>

求解 LP 问题有许多算法：

- **单纯形算法（Simplex algorithm）**：在**可行域（feasible region）**内，$x$ 沿着 $c$ 的方向**从一个顶点（vertex）移动到另一个顶点**。算法简单，但**最坏情况下运行时间为指数级**。
- **椭球算法（Ellipsoid algorithm）**：从**一个包含最优解的椭球**开始，不断**收缩椭球**直到找到最优解。这是**第一个多项式时间算法**，是一个**理论突破（theoretical breakthrough）**。然而，该算法在实践中**不可行**。

<span style="color:#c0392b">**5. 续（Algorithms for LP, cont.）**</span>

- **内点法（Interior Point Method）**：$x$ 在多面体（polytope）**内部**沿着 $c$ 的方向移动。该算法运行时间为**多项式级**，且**实用**。

本讲只研究单纯形算法。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 三类算法的对比本身就是一部**理论 vs 实践**的教材：**单纯形**（Dantzig，1940 年代）在最坏情形可能是指数的（Klee 与 Minty 于 1972 年构造的「Klee-Minty 立方体」上，单纯形要跑 $2^n - 1$ 轮），但**实际中几乎总是很快**，至今仍是教科书与工业求解器的主流；**椭球法**（Shor 提出雏形，Khachiyan 1979 证明多项式时间）是**第一个**保证多项式时间的 LP 算法，是纯理论突破，但数值上慢到不实用；**内点法**（Dikin 1967 首次发现，Karmarkar 1984 重新发明并给出 $O(n^{3.5}L)$ 复杂度）在理论上多项式、在实践中与单纯形同样快，是两者的「**双赢合成**」（维基百科 Interior-point method 词条的原话：理论上多项式——区别于单纯形的最坏指数；实践上同单纯形一样快——区别于椭球法的理论多项式但实践极慢）。这段历史也预告了下一讲的主题：**P vs NP**——LP 属于 P，但「LP 在 P 中」这个事实本身都费了半个世纪才被证明，可见「多项式时间存在性」远比想象中微妙。

<span style="color:#c0392b">**5.1 单纯形算法（Simplex Algorithm）**</span>

如前所述，单纯形算法在实践中表现良好，但**最坏情况下运行时间为指数级**。在高层面上，该算法就像是**在不等式/约束上做高斯消元（Gaussian elimination）**。单纯形算法的工作方式如下：

- 把 LP 表示为「**松弛形式（slack form）**」。
- 把一个松弛形式转换为**等价的松弛形式**，同时**尽可能增大**目标函数的值，并确保该值**不减小**。
- **重复**直到最优解变得显然。

<span style="color:#c0392b">**5.1.1 单纯形示例（Simplex Example）**</span>

考虑下面的例子：

```math
\begin{aligned}
\text{Minimize} \quad & 3x_1 + x_2 + x_3 \\
\text{Subject to} \quad
x_1 + x_2 + 3x_2 &\le 30 \\
2x_1 + 2x_2 + 5x_3 &\le 24 \\
4x_1 + x_2 + 2x_3 &\le 36 \\
x_1, x_2, x_3 &\ge 0
\end{aligned}
```

把给定的 LP 问题改写成**松弛形式**，由称为**非基变量（nonbasic variables）**的原始变量，和表示**松弛量（slack）**的、称为**基变量（basic variables）**的新变量组成：

```math
\begin{aligned}
z &= 3x_1 + x_2 + 2x_3 \\
x_4 &= 30 - x_1 - x_2 - 3x_3 \\
x_5 &= 24 - 2x_1 - 2x_2 - 5x_3 \\
x_6 &= 36 - 4x_1 - x_2 - 2x_3
\end{aligned}
```

我们从**一个基础解（basic solution）**开始：把右侧的**所有非基变量**设成某个可行值，再计算基变量的值。例如，我们可以设 $x_1 = x_2 = x_3 = 0$。注意**全零解**满足本题的所有约束，但在一般情况下可能不满足。

我们现在执行**旋转步骤（pivoting step）**：

> <span style="color:#1e8449;">**[note] Note（译者注，必须澄清的三处笔误）:**</span> 这里的原始 LP 与后面的松弛形式**并不一致**——这是原讲义的三处笔误，我逐一用代数验证过。**①** 目标函数写的是「Minimize $3x_1 + x_2 + x_3$」，但松弛形式却是 $z = 3x_1 + x_2 + 2x_3$，且整个算法都在**增大** $z$——因此意图显然是「**Maximize $3x_1 + x_2 + 2x_3$**」。**②** 第一条约束写的是「$x_1 + x_2 + 3x_2 \le 30$」，第二个 $x_2$ 应为 $x_3$（松弛形式 $x_4 = 30 - x_1 - x_2 - 3x_3$ 证明是 $3x_3$）。**③** 第 6 页中间有一行写「$x_2 = \frac{3}{2} - \cdots$」，代入 $z$ 验证可知左边应是 $x_3$。**判定方法**：以可验证的松弛形式与最终代数为准——我按 $z = 3x_1 + x_2 + 2x_3$ 把三步旋转全部算通，最后 $z = 28 - \frac{x_3}{6} - \frac{x_5}{6} - \frac{2x_6}{3}$，最优值 28、最优解 $(8, 4, 0)$，与 (2)(3) 两条约束同时取紧一致。翻译保留原文字样，但读者应按上述修正理解。

> <span style="color:#1e8449;">**[note] Note（译者注，松弛形式）:**</span> 松弛形式是单纯形的工作语言：每个 $\le$ 约束补上一个**松弛变量（slack variable）**把不等式变成等式（如 $x_1 + x_2 + 3x_3 \le 30 \Rightarrow x_1 + x_2 + 3x_3 + x_4 = 30$），$x_4, x_5, x_6 \ge 0$。松弛变量衡量「该约束还剩多少余地」：值为正表示约束**非紧（non-binding）**，为 0 表示**紧（binding）**。基变量「在左边」（$x_4, x_5, x_6$ 用非基变量表示），非基变量「在右边」（$x_1, x_2, x_3$）。**基础解**就是令所有非基变量为 0 得到的解——它恰是多面体的一个**顶点（vertex）**。全零解可行是这里的幸运：一般情形下初始顶点可能不可行，那就需要第 7 节的「两阶段法（two-phase method）」（见第 6 节末尾的开放问题）。

<span style="color:#c0392b">**5.1.1 旋转步骤（续）（Pivoting step, cont.）**</span>

- 选择目标函数中**系数为正**的非基变量 $x_e$。
- **尽可能增大** $x_e$ 的值，且不违反任何约束。
- 令 $x_e$ 成为**基变量**，同时某个其他基变量变为**非基变量**。

在这个例子中，我们可以增大 $x_1$ 的值。**第三条约束**会把 $x_1$ 限制为 9。我们得到

```math
x_1 = 9 - \frac{x_2}{4} - \frac{x_3}{2} - \frac{x_6}{4}
```

现在用 $x_6$ 在右侧改写其他约束：

```math
\begin{aligned}
z &= 27 + \frac{x_2}{4} + \frac{x_3}{2} - \frac{3x_6}{4} \\
x_1 &= 9 - \frac{x_2}{4} - \frac{x_3}{2} - \frac{x_6}{4} \\
x_4 &= 21 - \frac{3x_2}{4} - \frac{5x_3}{2} + \frac{x_6}{4} \\
x_5 &= 6 - \frac{3x_2}{2} - 4x_3 + \frac{x_6}{2}
\end{aligned}
```

我们注意到这些解是**等价的**：即，原来的基础解 $(0, 0, 0, 30, 24, 36)$ 满足改写后的约束，且目标值为 0；第二个基础解 $(9, 0, 0, 21, 6, 0)$ 的目标值为 27。

在这一点上，对 $x_6$ 进行旋转实际上会让目标值**下降**（这里不展示计算）。因此我们选 $x_3$ 作为下一个旋转变量，得到

```math
\begin{aligned}
z &= \frac{111}{4} + \frac{x_2}{16} - \frac{x_5}{8} - \frac{11x_6}{16} \\
x_1 &= \frac{33}{4} - \frac{x_2}{16} + \frac{x_5}{8} - \frac{5x_6}{16} \\
x_3 &= \frac{3}{2} - \frac{3x_2}{8} - \frac{x_5}{4} + \frac{x_6}{8} \\
x_4 &= \frac{69}{4} + \frac{3x_2}{16} + \frac{5x_5}{8} - \frac{x_6}{16}
\end{aligned}
```

这产生基础解 $\left( \frac{33}{4}, 0, \frac{3}{2}, \frac{69}{4}, 0, 0 \right)$，目标值为 $\frac{111}{4}$。

> <span style="color:#1e8449;">**[note] Note（译者注，旋转规则与最小比值检验）:**</span> 这一页演示了旋转的核心机制，值得逐行核对。**为什么是第三条约束把 $x_1$ 限制到 9？** 当 $x_2 = x_3 = 0$ 时，三条约束分别给 $x_1 \le 30, \; 12, \; 9$——**取最紧的那个**，即 $x_1 \le 9$。这正是单纯形中著名的**最小比值检验（minimum ratio test）**：每条约束（用非基变量表示的基变量方程）都对入基变量给出一个「到此为止」的上限，最紧的约束决定入基变量能走多远，同时**恰好把该约束对应的基变量挤成 0**（这里 $x_6$ 被挤出基，因为第三条约束变为等式 $4 \cdot 9 + 0 + 0 = 36$）。几何上，这一步就是**沿多面体的一条边从一个顶点（原点）走到相邻顶点** $(9, 0, 0)$，目标值从 0 升到 27。第二次旋转选 $x_3$ 而不是 $x_2$：此时目标函数 $z = 27 + \frac{x_2}{4} + \frac{x_3}{2} - \frac{3x_6}{4}$ 中 $x_6$ 系数为负（−3/4），把它转进基只会拉低 $z$，被排除；$x_3$ 系数 $\frac12$ 大于 $x_2$ 的 $\frac14$，按 Dantzig 规则（选正系数最大的变量）优先转 $x_3$，目标升到 $\frac{111}{4}$。🎥 *Devadas 把旋转的代数本质一句话讲透*："you can think of this as Gaussian elimination, except with inequalities."（翻译：你可以把它想成高斯消元，只是不等式版本。）——与你在 Strang 线性代数里学的消元/换基一脉相承。另注意原讲义此处第三行方程左边误印为 $x_2$，应为 $x_3$（见 5.1.1 笔误注 ③）。

<span style="color:#c0392b">**5.1.1 收敛（续）（Convergence, cont.）**</span>

最后，对 $x_2$ 进行旋转得到

```math
\begin{aligned}
z &= 28 - \frac{x_3}{6} - \frac{x_5}{6} - \frac{2x_6}{3} \\
x_1 &= 8 + \frac{x_3}{6} + \frac{x_5}{6} - \frac{x_6}{3} \\
x_2 &= 4 - \frac{8x_3}{3} - \frac{2x_5}{3} + \frac{x_6}{3} \\
x_4 &= 18 - \frac{x_3}{2} + \frac{x_5}{2}
\end{aligned}
```

虽然本讲不证明该算法的正确性，但当**所有非基变量的系数都为负**时，单纯形算法就找到了**最优解**。一般而言，单纯形算法**保证在 $\binom{n+m}{n}$ 次迭代内收敛**，其中 $n$ 是变量个数，$n + m$ 是约束个数。对一般的 $n$ 和 $m$，这可能是指数级的。

> <span style="color:#1e8449;">**[note] Note（译者注，最优性判据与迭代上界）:**</span> 最终松弛形式 $z = 28 - \frac{x_3}{6} - \frac{x_5}{6} - \frac{2x_6}{3}$ 中，所有非基变量（$x_3, x_5, x_6$）系数都是**负的**：只要它们任何一个取正值，$z$ 就变小，所以 $z \le 28$ 恒成立；而基础解 $(8, 4, 0, 18, 0, 0)$ 达到 $z = 28$。**「所有系数为负」本身就是一张最优性证书**——它和第 2 节政治例子的加权证书是同一套思想：在当前位置构造出「不可能更好」的局部证据。关于迭代上界 $\binom{n+m}{n}$：基变量是 $n + m$ 个变量（原始 $n$ 个 + 松弛 $m$ 个）中的 $n$ 个「在左边」的，不同基础解 = 不同的「选 $n$ 个做基」的组合，总数最多 $\binom{n+m}{n}$；若每次旋转都严格增大目标值（配合防循环的规则，如 Bland 规则，1977），就**不会回到同一个基础解**，故迭代数 ≤ 基础解个数——而 $\binom{n+m}{n}$ 对一般 $n, m$ 是指数级的（这正是最坏情形指数复杂度的来源，Klee-Minty 立方体把它实际化）。这个例子共 3 次旋转：$z$ 值 0 → 27 → 111/4 → 28，一路单调不减，最终收敛到顶点 $(8, 4, 0)$——两个紧约束（约束 2、3）恰好对应 $x_5 = x_6 = 0$。

<span style="color:#c0392b">**6. LP 的更多主题（More Topics of LP）**</span>

关于 LP，还有几个本讲未讨论的重要问题：

- 如何判断 LP 是否**可行（feasible）**？
- 如果 LP 可行，但**初始基础解不可行**怎么办？
- 如何判断 LP 是否**无界（unbounded）**？
- 如何**选择旋转变量（pivot）**？

这些问题在教科书和其他 LP 文献中有解答。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这四个「开放问题」其实都已有标准答案（讲义故意留作引子），在 CLRS 第 29 章与经典 LP 文献中有完整处理，这里给个速览：**①可行性**——引入人工变量构造辅助 LP 做**第一阶段（Phase I）**，可行当且仅当辅助最优值为 0；**②初始基础解不可行**——用**两阶段单纯形（two-phase simplex）**：第一阶段先找可行基础解，第二阶段再优化；**③无界**——若入基变量在**所有**基变量方程中都不受限制（系数都不限制它），可行域沿该方向无界，目标可无限增大；**④旋转规则**——Dantzig 规则（最大正系数）最直观，但可能循环；**Bland 最小下标规则（1977）**保证不循环，从而保证有限收敛。这些问题的存在也再次呼应主题：**单纯形**在实践中快但在理论上可能指数，而**多项式保证**要等椭球法/内点法（第 5 节）——这正是下一讲「P、NP、NP 完全、归约」的前奏：LP 属于 P，是「容易但解法曲折」的典型代表。

> <span style="color:#1e8449;">**[note] Note（译者注，回顾与前瞻）:**</span> 把整讲串成一条线：**建模**（政治竞选/最大流/最短路 → LP）→ **标准化**（第 3 节四条翻译规则）→ **验证**（最优性证书 = 对偶变量，第 1.1 节）→ **求解**（单纯形 = 沿多面体棱边走 + 松弛形式上的高斯消元，第 5 节）。这个「建模 → 归约 → 验证 → 求解」的闭环，与你在 6.006 里处理图问题的方式同构，只是这次**统一求解器**换成了 LP。预告你大二上学期要学的**凸优化（Boyd）**：LP 是其最特殊的一类——凸集上的线性目标；Boyd 的书会把这里「顶点/多面体/对偶」的几何直觉推广到一般凸问题的 **KKT 条件与拉格朗日对偶**，届时你会发现本讲的对偶只是一般对偶理论的特例。若想深入，可对照 CLRS 第 29 章（含单纯形的完整伪代码与两阶段法）。
